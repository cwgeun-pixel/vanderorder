# 밴더 주문 → 텔레그램

매주 밴더(거래처)에 넣는 주문을 휴대폰에서 체크하고, 버튼 한 번으로 텔레그램에 보내는 웹앱입니다.
서버 없이 브라우저만으로 동작합니다 (HTML/CSS/JS 3개 파일).

## 기능

- 밴더별 탭 (기본 2개: 밴더 A, 밴더 B — 이름 변경·추가·삭제 가능)
- 품목마다 체크 + 수량(＋/− 버튼 또는 직접 입력, 0.5 같은 소수도 가능)
- **지난번 체크·수량이 그대로 남아 있음** → 매주 바뀐 것만 고치고 보내면 됨
- 메모 (예: "화요일 오전 배송 부탁드립니다")
- 보내기 전 미리보기, 복사 버튼
- 밴더별로 받는 채팅을 다르게 지정 가능 (예: 밴더 사장님 텔레그램으로 바로 전송)
- 보낸 기록 30건 보관, 백업 내보내기/가져오기

보내지는 메시지 예시:

```
📦 [우리가게] 밴더 A 주문
📅 2026-11-14 (토)

1. 양파 — 2 박스
2. 대파 — 3 kg
3. 계란 — 1 판

총 3개 품목

📝 화요일 오전 배송 부탁드립니다
```

## 처음 설정 (5분)

### 1. 텔레그램 봇 만들기
1. 텔레그램에서 **@BotFather** 검색 → 대화 시작
2. `/newbot` 입력 → 봇 이름과 아이디(끝이 `bot`) 입력
3. 받은 **토큰**(`123456789:AA...` 형태)을 복사

### 2. 봇에게 말 걸기
- 내가 받을 거면: 만든 봇을 검색해서 `/start` 를 보냅니다.
- 그룹방(직원들과 공유)으로 받으려면: 그룹에 봇을 초대하고 그룹에 아무 메시지나 남깁니다.

### 3. 앱에서 설정
1. 앱 오른쪽 위 **⚙︎ 설정**
2. 봇 토큰 붙여넣기
3. **채팅 ID 찾기** → 나온 채팅을 누르면 자동 입력
4. **테스트 메시지** 로 확인 → **저장**

### 4. 품목 등록
오른쪽 위 **편집** → 밴더 이름 변경, 품목 이름/단위 추가, ↑↓ 로 순서 변경 → **완료**

## 휴대폰에서 쓰는 법 (GitHub Pages로 올리기)

1. 이 저장소를 GitHub에 올리고 기본 브랜치(main)에 병합
2. GitHub 저장소 → **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main` / `(root)` → Save
3. 1~2분 뒤 `https://<아이디>.github.io/vanderorder/` 주소로 접속
4. 휴대폰 브라우저에서 **홈 화면에 추가** 하면 앱처럼 쓸 수 있습니다.

> PC에서 바로 써 보려면 `index.html` 파일을 브라우저로 열어도 됩니다.

## 주의사항

- 품목·수량·토큰은 **그 기기의 브라우저에만** 저장됩니다. 휴대폰과 PC는 따로 설정해야 하며,
  설정 → 백업 **내보내기/가져오기**로 품목 목록을 옮길 수 있습니다 (토큰은 백업에 포함되지 않음).
- 봇 토큰은 비밀번호와 같습니다. 코드나 저장소에 적지 말고 앱 설정에만 입력하세요.
  토큰이 유출되면 @BotFather 에서 `/revoke` 로 새로 발급받으면 됩니다.
- 브라우저 데이터를 지우면 저장된 내용도 지워지니, 품목을 정리한 뒤 한 번 백업해 두세요.
